# boat

This repository holds the sailboat software.

- `jetson/` is the ROS 2 workspace that runs on the Jetson. See [jetson/setup/README.md](jetson/setup/README.md).
- `teensy/` is the Teensy 4.0 firmware. See [teensy/README.md](teensy/README.md).

Changes under `jetson/` run [Jetson CI](.github/workflows/jetson.yml). Changes under `teensy/` run [Teensy CI](.github/workflows/teensy.yml).
